# AI Agents

Nexora includes specialist AI Agents that share one OS — memory, reasoning, and tools.

## Agent concept

- Specialists that share one operating layer.
- Living agent cards on the marketing site show specialists collaborating on real workflows.
- Agents route through understand → reason → plan → execute → learn → remember.

## What agents can do

- Interpret intent from chat.
- Retrieve workspace memory.
- Compile multi-step plans.
- Call live tools (Slack, Notion).
- Request approvals for high-risk steps.
- Write outcomes back into memory.

## Onboarding after signup

1. Register / login (email or Google depending on config).
2. Land in `/app/dashboard` (product workspace).
3. Connect integrations under `/app/integrations`.
4. Use Chat to issue commands.
5. Review Approvals for gated actions.
6. Admins manage users under `/app/admin`.
