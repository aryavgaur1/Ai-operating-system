# Nexora — Work Action OS

Nexora is not a chatbot. It is a **Work Action OS** with a human gate.

## Exact product line (say this)

**Nexora proposes real work in Slack, Jira, and Notion — then waits for a human to Approve & run before anything executes.**

Short form:

**Propose → Approve → Act.**

## Beachhead loop

1. Ask in Chat (e.g. “Create a Jira ticket to track the vendor contract follow-up”)
2. Review in Approvals (risk, what will change, blast radius)
3. Approve & run — live tool execution with verification
4. Timeline / audit remembers what was decided

## Competitive wedge

- Glean finds information
- Sierra answers customers
- **Nexora executes work with a human gate** across the tools ops/PM teams already use (Slack + Jira + Notion)
