# Integrations

Nexora connects the tools teams already use. Hover accordion and hub on the marketing site highlight:

## Live today

- **Slack** — Channels, messages, history, summaries. Critical context from threads becomes actionable. Live bot token / OAuth path depending on mode.
- **Notion** — Create and update pages in your workspace. Docs and launch plans stop being siloed.

## Featured / roadmap connectors (marketing surface)

- Gmail — Draft replies and route follow-ups.
- Jira — Bridge tickets to business context.
- Zoom — Capture decisions and next steps.
- Asana — Keep project context aligned.
- Microsoft 365 — Bring Office/SharePoint work into one execution layer.
- Discord — Route community signal into workflows.
- Salesforce — Connect CRM to real execution.
- GitHub — Mentioned in network visualizations; ask for current live status — Slack & Notion are the production live tools today.
- Google Drive / Calendar — Represented in product vision and network maps; not claimed as live API execution unless enabled.

## How Slack integration works

1. Connect Slack (demo shared credentials or per-user OAuth in SaaS mode).
2. Ask Nexora in natural language (create channel, post message, list channels, summarize discussion).
3. Reasoning + planning selects Slack tools.
4. High-impact actions can require **Approvals**.
5. Results return in chat with an observable execution trail.

## How Notion integration works

1. Connect Notion with an integration token / OAuth.
2. Ask to create or update pages (Investor Notes, Weekly Report, docs).
3. Pages are created in **your** Notion workspace via the API — not simulated.

## Honesty rule

If a connector is shown as marketing/roadmap but not live, say: "Shown on the marketing surface; live execution today is Slack and Notion. Others are on the roadmap."
