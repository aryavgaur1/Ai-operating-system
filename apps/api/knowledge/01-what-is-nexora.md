# What is Nexora?

Nexora is an **AI Operating System** for modern teams — not a chatbot.

It connects your apps, understands business context, reasons over work, and **executes real actions** through live tool APIs (Slack, Notion, and expanding connectors).

## Positioning

- One AI. Every Tool. Complete Automation.
- Command surface for work — not slideware demos.
- Plans multi-step work before acting.
- Persistent workspace memory across tools and time.
- Human-in-the-loop approvals for high-impact steps.

## How Nexora differs from ChatGPT

| ChatGPT | Nexora |
|---------|--------|
| Answers questions | Executes work across your stack |
| No live tool ops by default | Live Slack & Notion API actions |
| Session chat | Persistent AI memory + history |
| Single assistant | Multi-agent OS with routing |
| No enterprise approval gates | Approvals, audit, roles |

Nexora is the **operating layer** between AI and the tools teams already use.
